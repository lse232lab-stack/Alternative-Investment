# 인사담당자/실무면접용 프로젝트 포지셔닝

이 프로젝트의 목적은 "LLM에게 부동산 재무모델을 만들어 달라고 요청했다"는 수준을 피하는 것이다. 핵심 메시지는 다음과 같다.

```text
AI가 모델을 만든 것이 아니라,
대체투자 실무의 검토 프레임을 코드로 구조화했고,
AI는 반복적인 입력 정리와 메모 작성 보조에만 제한적으로 활용한다.
```

## 1. 왜 단순 LLM 산출물이 아닌가

단순 LLM 산출물은 보통 다음 한계를 갖는다.

```text
수식의 일관성을 검증하기 어렵다.
가정 변경 시 전체 모델이 안정적으로 연동되는지 확인하기 어렵다.
IRR, DSCR, Exit Value가 어떤 논리로 계산됐는지 추적하기 어렵다.
회사별 투자/대출 심사 관점 차이가 반영되지 않는다.
```

이 프로젝트는 이를 피하기 위해 다음 구조로 설계했다.

```text
계산 엔진: Python 함수로 고정
입력 구조: DealAssumptions dataclass로 통제
수익률 검증: unittest와 Excel 수식 검산
리스크 점검: 규칙 기반 자동 체크
기관별 관점: PF, 운용사, 보험사 렌즈 분리
AI 역할: 자연어 입력 구조화와 메모 초안 보조로 제한
```

즉, LLM이 임의로 계산한 결과가 아니라, 재무모델의 흐름을 직접 코드로 정의한 프로젝트다.

## 2. 회사 유형별로 드러내야 할 고민

### 2.1 증권사 PF / 부동산금융

증권사 PF 또는 부동산금융 부서에서는 투자자의 IRR보다 대출 회수 가능성과 담보 안정성이 중요하다.

강조할 기능:

```text
Debt Schedule
DSCR
ICR
Debt Yield
LTV
Exit 시 대출잔액 상환 구조
금리 상승 시 DSCR 압박
```

면접 설명:

```text
증권사 관점에서는 자기자본 IRR보다 대출 원리금 상환 가능성이 중요하다고 보고, DSCR과 Debt Yield를 별도 지표로 계산했습니다. 특히 Interest-only 구조에서는 보유기간 중 현금흐름이 좋아 보일 수 있지만, 매각 시점에 대출잔액 상환 리스크가 집중되기 때문에 Exit Value 의존도를 별도로 점검하도록 했습니다.
```

이 회사군에서 보여줄 깊이는 다음이다.

```text
대출 가능 금액은 단순 LTV만으로 정해지지 않는다.
NOI 기반 DSCR과 Debt Yield가 함께 봐야 한다.
금리 상승과 Exit 지연은 대출 회수 리스크로 연결된다.
```

### 2.2 대체투자운용사

운용사에서는 투자심의위원회 관점이 중요하다. 즉, 목표수익률을 맞추는지뿐 아니라 그 수익률이 어떤 원천에서 나오는지 설명할 수 있어야 한다.

강조할 기능:

```text
Levered IRR
Unlevered IRR
Equity Multiple
Cash-on-Cash Yield
Exit Cap x Rent Growth 민감도
목표 IRR 기준 최대 매입가 역산
수익 중 매각차익 의존도
```

면접 설명:

```text
운용사 관점에서는 기준 IRR 하나보다 수익률의 원천이 중요하다고 봤습니다. 따라서 Levered IRR과 Unlevered IRR을 함께 계산해 레버리지 효과를 분리했고, Exit Cap과 임대료 성장률 민감도를 통해 투자수익률이 매각가정에 얼마나 의존하는지 확인하도록 했습니다. 또한 목표 IRR을 만족하는 최대 매입가를 역산해 실제 입찰 또는 가격협상 관점으로 연결했습니다.
```

이 회사군에서 보여줄 깊이는 다음이다.

```text
IRR은 높을수록 좋은 숫자가 아니라, 어떤 가정에 의해 만들어졌는지가 중요하다.
매각차익 의존도가 높으면 안정적 income deal이 아니라 exit-driven deal에 가깝다.
목표수익률 기준 최대 매입가는 투자판단과 가격협상의 연결고리다.
```

### 2.3 보험사 자산운용 / 장기투자자

보험사 자산운용은 일반적인 opportunistic fund보다 안정성, 현금흐름 예측가능성, 자본보전 관점이 더 중요하다.

강조할 기능:

```text
Cash-on-Cash Yield
NOI 안정성
DSCR
Debt Yield
Exit Value 의존도
보유기간 중 배당 가능 현금흐름
```

면접 설명:

```text
보험사 자산운용 관점에서는 단순히 높은 Levered IRR보다 장기적으로 안정적인 배당과 원금보전 가능성이 중요하다고 봤습니다. 그래서 평균 Cash-on-Cash Yield, DSCR, Debt Yield, 매각차익 의존도를 함께 보여주도록 했습니다. Exit Value 비중이 과도하면 장기 안정형 투자자에게는 리스크로 볼 수 있기 때문에 별도 경고로 표시했습니다.
```

이 회사군에서 보여줄 깊이는 다음이다.

```text
보험사에는 높은 IRR보다 안정적인 현금흐름이 더 중요할 수 있다.
Exit 의존도가 높은 구조는 장기 ALM 관점에서 불편할 수 있다.
부동산 대체투자는 자산수익률뿐 아니라 부채/자본 성격과도 맞아야 한다.
```

## 3. 앱에 반영된 차별화 기능

이번 버전에는 `Institution Lens` 탭을 추가했다. 같은 딜을 세 가지 관점으로 다시 해석한다.

```text
증권사 PF / 대출 심사 관점
대체투자운용사 / 투자심의 관점
보험사 자산운용 / 장기 ALM 관점
```

각 관점은 다음 세 가지를 제시한다.

```text
Key Metrics: 해당 기관이 중점적으로 볼 숫자
Interpretation: 그 숫자를 어떻게 해석해야 하는지
Diligence Questions: 실사와 면접에서 이어질 질문
```

이 기능은 포트폴리오에서 매우 중요하다. 같은 부동산 딜도 회사 유형에 따라 판단 기준이 달라진다는 점을 코드와 화면에서 보여주기 때문이다.

## 4. 프로젝트 설명 문장

자기소개서나 포트폴리오 첫 문단에는 다음처럼 쓸 수 있다.

```text
오피스 매입 가정을 기반으로 NOI, Debt Schedule, Exit Value, Levered/Unlevered IRR, DSCR, Debt Yield를 계산하고, 민감도 분석과 목표수익률 기준 최대 매입가 역산을 수행하는 대체투자 Underwriting Copilot을 구축했습니다. 단순히 LLM에 모델 작성을 맡기는 방식이 아니라, 계산 엔진은 Python으로 직접 구현하고 AI는 자연어 입력 구조화와 투자검토 메모 보조에만 활용하도록 설계했습니다. 또한 동일한 딜을 증권사 PF, 대체투자운용사, 보험사 자산운용 관점에서 각각 다르게 해석하는 Institution Lens를 추가해 회사별 투자/심사 기준의 차이를 반영했습니다.
```

## 5. 면접 예상 질문과 답변 방향

### Q1. 왜 실제 딜이 아니라 가상 딜인가요?

답변 방향:

```text
실제 IM이나 렌트롤은 비공개 자료인 경우가 많아 취업준비자가 접근하기 어렵습니다. 그래서 특정 실거래를 복제하기보다 안정화 오피스 매입이라는 일반적인 투자 구조를 가정하고, Year 1 NOI와 Entry Cap을 기준으로 매입가를 설정했습니다. 핵심은 실제 딜명보다 재무모델의 구조와 리스크 검토 프레임을 이해하고 구현하는 것이라고 판단했습니다.
```

### Q2. AI가 해준 것과 무엇이 다른가요?

답변 방향:

```text
LLM은 문장 생성에는 강하지만 재무모델 계산의 일관성과 검증가능성에는 한계가 있다고 봤습니다. 그래서 NOI, Exit Value, Debt Schedule, IRR, DSCR 등 핵심 계산은 모두 Python 함수로 고정했고, 테스트와 Excel 검산을 통해 확인하도록 했습니다. AI는 향후 자연어 딜 설명을 입력값으로 구조화하거나 투자검토 메모 초안을 작성하는 보조 역할로 제한했습니다.
```

### Q3. 어떤 부분에서 대체투자 이해가 드러나나요?

답변 방향:

```text
단순히 IRR만 계산하지 않고, Unlevered IRR과 Levered IRR을 분리해 레버리지 효과를 봤고, DSCR과 Debt Yield로 대출 안정성을 점검했습니다. 또한 Exit Cap과 임대료 성장률 민감도, 목표 IRR 기준 최대 매입가 역산, 매각차익 의존도 점검을 넣어 투자심의에서 실제로 질문될 만한 포인트를 반영했습니다. 추가로 증권사 PF, 운용사, 보험사 관점에서 같은 딜을 다르게 해석하는 탭을 만들어 회사별 판단 기준 차이를 반영했습니다.
```

## 6. 다음에 추가하면 더 강해지는 기능

가장 강한 다음 단계는 렌트롤 분석이다.

```text
임차인별 면적, 임대료, 만기, 보증금 입력
WALE 계산
상위 임차인 집중도
연도별 만기 집중도
공실면적 계산
만기 리스크가 NOI와 Exit Value에 미치는 영향
```

렌트롤 분석이 붙으면 프로젝트가 단순 가정 모델에서 실제 자산 실사 도구에 가까워진다.
